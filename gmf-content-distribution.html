Add a single article

Paste the title, URL, and body text (HTML or plain text — any <a href> links inside are read automatically as existing internal links).

Bulk import

Paste multiple articles at once. Separate each with a line containing only ---. First line: Title: ..., second line: URL: ..., everything after is content.

Your articles

Inbound link counts update automatically as you add articles containing links to each other.

Generate a content set

Pick an article. Claude will draft platform-specific social posts, short-form hooks, discussion questions, and a promo snippet — each pointing back to this article and the free calculator. New drafts land in the Queue for your review.

How duplicates are avoided

Every draft is checked against everything already in your queue for that article using text-overlap similarity. Anything too close to existing content (paraphrase or near-repeat) is discarded automatically rather than added, so you never end up approving the same post twice.

Orphan articles

Articles with no other article in your library linking to them. Highest priority for internal-link additions.

Suggested internal links

Topic overlap between articles that aren't already linked to each other. Add these links manually in the GitHub editor — this tool doesn't touch your site.

Site settings

Used in generated CTAs. Change these if your domain or calculator path differs.
